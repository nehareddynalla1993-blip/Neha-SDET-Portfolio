## Easiest way to update your existing repository

1. Download and unzip the **personalized** portfolio ZIP.
2. Open your GitHub repository at [https://github.com/nehareddynalla1993-blip/Neha-SDET-Portfolio](https://github.com/nehareddynalla1993-blip/Neha-SDET-Portfolio).
3. If you haven't uploaded any files yet: choose **uploading an existing file**, then drag the contents of the extracted folder. Do not upload the ZIP itself.
4. If you already uploaded the earlier files: replace `README.md` and `index.html`, and add the new `case-studies/regression-reliability-playbook.md`. The easiest way to replace a file in the browser is to open it, choose the pencil **Edit** icon, paste the updated content, and **Commit changes**.
5. Enable **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
6. Open the website address above after deployment finishes.

**Mac:** In Finder, press `Command + Shift + .` to reveal the hidden `.github` directory if you are uploading the whole project for the first time.
